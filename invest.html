怎么新增场景 维护说明

每次学到新的投资认知、或遇到重要决策时，按以下流程沉淀：

  1. 新建业务场景页（命名：invest-<场景>.html）
  2. 按"8 章节标准结构"组织内容（背景/公式/机制/对比/案例/启示/FAQ/变更日志）
  3. 在本页（invest.html）加场景卡片
  4. 更新 business-scenarios.html 和 site-map.html 的入口
  5. 走 Contents API 推到 GitHub Pages

完整规范见：关键文件总览 中的"信息化驾驶舱 · 网站标准手册"。
