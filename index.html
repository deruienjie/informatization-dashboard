🎯 决策关键 · 不在钱 在场景

✅ 适合买车的场景

🚇 通勤距离 > 15km（地铁超过 1 小时）
🏖️ 周末外出 > 4 次/月（租车周末紧俏）
🏠 回梅州 > 4 次/年（春节以外的节假日也回）
👶 3-5 年内有生育计划（带娃出行刚需）
💼 工作需要车辆（如客户拜访、跑工地）
💰 现金充裕（10 万购车不影响生活质量）

✅ 适合租车的场景

🚇 通勤距离 < 10km（地铁/打车足够）
🏠 周末外出 < 2 次/月（生活规律）
🏠 回梅州 < 2 次/年（节假日合并租车）
💰 现金紧张（10 万购车款用来付首付更划算）
🎯 追求灵活（想换不同车型体验）
🚗 怕麻烦（保养、剐蹭、保险都不用操心）

📐 关键参数与计算公式

📐 方案一 公式
年均成本 = 车价分摊 + 折旧 + 保险 + 充电 + 停车 + 其他
         = 12,500 + 14,000 + 7,000 + 1,500 + 6,000 + 2,600
         = 43,600 元/年

扣除车价分摊（不计入现金流）：
实际使用成本 = 31,100 元/年
10 年使用成本 ≈ 280,000 - 100,000 残值
         = 28,000 元/年（按 8 年使用）
📐 方案二 公式
年均成本 = 节假日 + 偶尔 + 网约车
         = (春节 + 五一 + 国庆 + 元旦 + 清明 + 端午 + 中秋)
         + 周末偶尔 + 网约车
         = (10000 + 3000 + 4900 + 1500 + 1200×3)
         + 3200 + 2400
         = 28,600 元/年

弹性调整：
• 多 1 次周末 → +400
• 多回 1 次家 → +2,500

💡 我的建议 · 暂缓买车，先租车

当前优先级：房子首付 > 车子使用
10 万购车款 ≈ 首付 6% 加分项，或可作 1 年的家庭应急储备
建议行动（未来 3-6 个月）：
  1. 先租房 6-12 个月，体验真实用车需求
  2. 记录每次租车的实际频次 + 真实成本
  3. 若 6 个月后月均租车 > 3000 元 → 重新评估买车
  4. 若买房落地、装修完成 → 重新评估是否需要长期用车
⚠️ 重新评估的触发条件：① 回梅州 > 3 次/年 ② 周末租车溢价严重（节假日租不到）③ 通勤场景变化（如换工作到更远的地方）
